# Система сетки для редактирования отсеков

## Обзор

Реализована новая система редактирования отсеков с сеткой и перетаскиванием (drag-and-drop).

## Основные возможности

### 1. Сетка поверх изображения
- Размер клетки: 10×10 пикселей
- Автоматическое создание сетки поверх фонового изображения
- Возможность включения/отключения отображения сетки
- Визуальная привязка к клеткам сетки

### 2. Перетаскивание отсеков (Drag-and-Drop)
- Свободное перемещение отсеков мышкой
- Привязка к сетке при перетаскивании
- Визуальная обратная связь:
  - Жёлтая рамка - выбранный отсек
  - Синяя рамка - перетаскиваемый отсек
- Ограничение перемещения в пределах сетки

### 3. Добавление отсеков
- Кнопка "➕ Добавить отсек"
- Новый отсек появляется в начале координат
- Автоматическое создание с базовыми параметрами
- Счётчик отсеков обновляется в реальном времени

### 4. Удаление отсеков
- Выбор отсека кликом мыши
- Кнопка "🗑️ Удалить отсек" в панели свойств
- Удаление через контекстное меню (в разработке)

## Режим "🔲 Сетка"

### Интерфейс

**Панель управления:**
- 📁 Загрузить изображение - загрузка фонового изображения корабля
- ✕ Удалить изображение - удаление фонового изображения
- ➕ Добавить отсек - добавление нового отсека
- ☑️ Сетка - включение/отключение отображения сетки
- ☑️ Отсеки - включение/отключение отображения отсеков
- Прозрачность - слайдер для настройки прозрачности отсеков (0-100%)
- 📊 Отсеков: N - счётчик отсеков на слое

**SVG холст:**
- Размер: 500×250 пикселей
- Сетка: 10×10 пикселей
- Отступы: 10 пикселей со всех сторон
- Метки: НОС (слева), КОРМА (справа)

### Рабочий процесс

#### Шаг 1: Загрузка изображения
1. Перейдите в режим "🔲 Сетка"
2. Нажмите "📁 Загрузить изображение"
3. Выберите файл с боковой проекцией корабля
4. Изображение появится на нижнем слое с прозрачностью 80%

#### Шаг 2: Настройка отображения
1. Включите отображение сетки (по умолчанию включено)
2. Включите отображение отсеков (по умолчанию включено)
3. Настройте прозрачность отсеков (рекомендуется 70%)

#### Шаг 3: Добавление отсеков
**Способ 1: Кнопка добавления**
1. Нажмите "➕ Добавить отсек"
2. Новый отсек появится в левом верхнем углу
3. Перетащите его в нужное место

**Способ 2: Автоматическое создание**
- При загрузке корабля из базы данных отсеки создаются автоматически
- Количество зависит от длины корабля и типа

#### Шаг 4: Перетаскивание отсеков
1. Наведите курсор на отсек
2. Зажмите левую кнопку мыши
3. Перетащите отсек в нужное место
4. Отпустите кнопку мыши
5. Отсек привяжется к ближайшей клетке сетки

#### Шаг 5: Редактирование свойств
1. Кликните по отсеку для выбора
2. Откроется панель свойств
3. Измените параметры:
   - Палуба (upper/middle/lower)
   - Позиция (bow/forward/mid/aft/stern)
   - Статус (intact/damaged/flooded/on_fire/destroyed)
4. Или удалите отсек кнопкой "🗑️ Удалить отсек"

## Технические детали

### Структура данных

```typescript
interface DraggableCompartment extends Compartment {
  gridX: number;      // Позиция X в клетках сетки
  gridY: number;      // Позиция Y в клетках сетки
  width: number;      // Ширина в клетках (по умолчанию 2)
  height: number;     // Высота в клетках (по умолчанию 2)
}
```

### Параметры сетки

```typescript
const gridSize = 10;        // Размер клетки в пикселях
const width = 500;          // Ширина холста
const height = 250;         // Высота холста
const padding = 10;         // Отступы
const cols = 48;            // Количество колонок
const rows = 23;            // Количество строк
```

### Привязка к сетке

```typescript
// Вычисляем новую позицию с привязкой к сетке
const newGridX = Math.round((mouseX - dragOffset.x) / gridSize);
const newGridY = Math.round((mouseY - dragOffset.y) / gridSize);

// Ограничиваем в пределах сетки
const clampedX = Math.max(0, Math.min(newGridX, cols - comp.width));
const clampedY = Math.max(0, Math.min(newGridY, rows - comp.height));
```

### Обработка событий

```typescript
// Начало перетаскивания
onMouseDown={(e) => handleMouseDown(e, comp.id)}

// Перемещение
onMouseMove={handleMouseMove}

// Завершение перетаскивания
onMouseUp={handleMouseUp}
onMouseLeave={handleMouseUp}
```

## Сравнение с другими режимами

### Режим "🎨 Слои" (Layer Editor)
- Рисование отсеков мышкой
- Автоматическое определение палубы и позиции
- Нет сетки
- Нет перетаскивания

### Режим "🔲 Сетка" (Grid Editor) - НОВЫЙ
- Сетка поверх изображения
- Свободное перетаскивание отсеков
- Привязка к клеткам сетки
- Кнопка добавления отсеков
- Более гибкое размещение

### Режим "✏️ Редактор" (Editor)
- Простое рисование прямоугольников
- Нет фонового изображения
- Нет сетки
- Базовое редактирование

## Примеры использования

### Пример 1: Точное размещение отсеков

```
1. Загрузите изображение линкора Ямато
2. Включите сетку
3. Установите прозрачность 60%
4. Добавьте отсек кнопкой "➕ Добавить отсек"
5. Перетащите отсек в область носовой башни
6. Привяжите к клеткам сетки для точного размещения
7. Повторите для других башен и надстроек
```

### Пример 2: Моделирование повреждений

```
1. Загрузите изображение корабля
2. Добавьте отсеки в местах предполагаемых попаданий
3. Перетащите отсеки на нужные позиции
4. Выберите каждый отсек
5. Измените статус на "damaged" или "destroyed"
6. Добавьте индикаторы затопления/пожара
7. Наблюдайте распространение повреждений в реальном времени
```

### Пример 3: Создание пользовательской схемы

```
1. Загрузите изображение корабля
2. Включите сетку для точного размещения
3. Добавьте необходимое количество отсеков
4. Перетащите каждый отсек в нужное место
5. Настройте размеры (в разработке)
6. Измените свойства каждого отсека
7. Сохраните схему (в разработке)
```
