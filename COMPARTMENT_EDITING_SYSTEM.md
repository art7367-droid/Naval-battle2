# Система редактирования отсеков кораблей

## Обзор проекта

Реализована комплексная система редактирования отсеков кораблей с тремя режимами работы:
1. **Режим "🎨 Слои"** - рисование отсеков поверх изображения
2. **Режим "🔲 Сетка"** - перетаскивание отсеков по сетке (drag-and-drop)
3. **Режим "✏️ Редактор"** - базовое рисование прямоугольников

## Основные возможности

### 1. Загрузка фонового изображения
- Поддержка форматов: PNG, JPG, SVG
- Drag-and-drop или выбор файла
- Автоматическое масштабирование под размер холста
- Прозрачность 80% для лучшего видимого эффекта

### 2. Система сетки
- Размер клетки: 10×10 пикселей
- Автоматическое создание поверх изображения
- Включение/отключение отображения
- Привязка отсеков к клеткам сетки

### 3. Перетаскивание отсеков (Drag-and-Drop)
- Свободное перемещение мышкой
- Привязка к сетке при отпускании
- Визуальная обратная связь (жёлтая/синяя рамка)
- Ограничение в пределах холста

### 4. Управление отсеками
- Добавление новых отсеков кнопкой
- Удаление через панель свойств
- Редактирование свойств (палуба, позиция, статус)
- Счётчик отсеков в реальном времени

### 5. Визуализация состояний
- 🟢 Зелёный - целый отсек
- 🟠 Оранжевый - повреждённый
- 🔵 Синий - затопленный
- 🔴 Красный - разрушенный
- 💧 Индикатор затопления
- 🔥 Индикатор пожара

## Режимы редактирования

### Режим "🎨 Слои" (Layer Editor)

**Особенности:**
- Рисование отсеков мышкой (зажать и тянуть)
- Автоматическое определение палубы и позиции
- Нет сетки
- Нет перетаскивания
- Подходит для быстрого создания схемы

**Использование:**
1. Загрузите изображение корабля
2. Зажмите левую кнопку мыши
3. Нарисуйте прямоугольник отсека
4. Отпустите кнопку - отсек создан
5. Повторите для остальных отсеков

### Режим "🔲 Сетка" (Grid Editor) - РЕКОМЕНДУЕТСЯ

**Особенности:**
- Сетка 10×10 пикселей поверх изображения
- Свободное перетаскивание отсеков
- Привязка к клеткам сетки
- Кнопка добавления отсеков
- Точное размещение

**Использование:**
1. Загрузите изображение корабля
2. Включите отображение сетки
3. Нажмите "➕ Добавить отсек"
4. Перетащите отсек в нужное место
5. Отсек привяжется к сетке
6. Настройте свойства в панели

### Режим "✏️ Редактор" (Editor)

**Особенности:**
- Простое рисование прямоугольников
- Нет фонового изображения
- Нет сетки
- Базовое редактирование
- Подходит для простых схем

**Использование:**
1. Выберите инструмент "✏️ Добавить отсек"
2. Нарисуйте прямоугольник
3. Выберите инструмент "🖱️ Выбор"
4. Кликните по отсеку для редактирования
5. Измените свойства в панели

## Технические детали

### Структура данных

```typescript
interface Compartment {
  id: string;
  position: CompartmentPosition;  // bow/forward/mid/aft/stern
  deck: CompartmentDeck;          // upper/middle/lower
  side: CompartmentSide;          // port/center/starboard
  name: string;
  maxHP: number;
  currentHP: number;
  status: CompartmentStatus;      // intact/damaged/flooded/destroyed/on_fire
  watertight: boolean;
  armor: number;
  flooded: number;                // 0.0-1.0
  fire: number;                   // 0.0-1.0
  components: Component[];
  adjacentIds: string[];
  lengthMeters?: number;
  positionFromBow?: number;
}

interface DraggableCompartment extends Compartment {
  gridX: number;      // Позиция X в клетках сетки
  gridY: number;      // Позиция Y в клетках сетки
  width: number;      // Ширина в клетках
  height: number;     // Высота в клетках
}
```

### Параметры холста

```typescript
const width = 500;          // Ширина холста
const height = 250;         // Высота холста
const padding = 10;         // Отступы
const gridSize = 10;        // Размер клетки сетки
const cols = 48;            // Количество колонок
const rows = 23;            // Количество строк
```

### Алгоритм привязки к сетке

```typescript
// Вычисляем новую позицию
const newGridX = Math.round((mouseX - dragOffset.x) / gridSize);
const newGridY = Math.round((mouseY - dragOffset.y) / gridSize);

// Ограничиваем в пределах сетки
const clampedX = Math.max(0, Math.min(newGridX, cols - comp.width));
const clampedY = Math.max(0, Math.min(newGridY, rows - comp.height));

// Обновляем позицию отсека
const updatedCompartment = {
  ...comp,
  gridX: clampedX,
  gridY: clampedY,
  positionFromBow: clampedX * 10  // Конвертируем в метры
};
```

## Рабочие процессы

### Сценарий 1: Создание схемы линкора

```
1. Перейдите в режим "🔲 Сетка"
2. Загрузите изображение линкора Ямато
3. Включите отображение сетки
4. Установите прозрачность 60%
5. Добавьте 27 отсеков (по одному на каждые 10 метров)
6. Разместите отсеки по палубам:
   - Верхняя палуба: Y = 0-2
   - Средняя палуба: Y = 3-5
   - Нижняя палуба: Y = 6-8
7. Настройте свойства каждого отсека
8. Сохраните схему
```

### Сценарий 2: Моделирование повреждений

```
1. Загрузите изображение корабля
2. Перейдите в режим "🔲 Сетка"
3. Добавьте отсеки в местах попаданий
4. Перетащите отсеки на нужные позиции
5. Выберите каждый отсек
6. Измените статус:
   - "damaged" - повреждён
   - "flooded" - затоплен
   - "on_fire" - пожар
   - "destroyed" - разрушен
7. Добавьте индикаторы затопления/пожара
8. Наблюдайте распространение повреждений
```

### Сценарий 3: Быстрое создание схемы

```
1. Перейдите в режим "🎨 Слои"
2. Загрузите изображение корабля
3. Установите прозрачность 70%
4. Зажмите левую кнопку мыши
5. Нарисуйте прямоугольник отсека
6. Отпустите кнопку - отсек создан
7. Повторите для всех отсеков
8. Настройте свойства через панель
```
