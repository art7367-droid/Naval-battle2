# Система слоёв для визуализации кораблей

## Обзор

Реализована система слоёв для вида сбоку корабля, позволяющая наложить полупрозрачные отсеки поверх фонового изображения корабля.

## Структура слоёв

### Слой 1: Фоновое изображение (нижний слой)
- Изображение корабля (боковая проекция)
- Формат: PNG, JPG, SVG
- Загрузка через интерфейс
- Отображается с прозрачностью 80%

### Слой 2: Отсеки (верхний слой)
- Полупрозрачные отсеки поверх изображения
- Настраиваемая прозрачность (0-100%)
- Цветовая индикация состояния отсеков
- Возможность включения/отключения отображения

## Режимы отображения

### 1. 📐 Схема (Schematic)
- Стандартная схема с отсеками
- Поддержка фонового изображения
- Настраиваемая прозрачность отсеков

### 2. 📁 Загрузка (Upload)
- Загрузка собственного изображения корабля
- Drag-and-drop или выбор файла
- Поддержка PNG, JPG, SVG

### 3. 🖼️ Готовое (Preset)
- Готовые SVG-схемы для типов кораблей
- Линкор, крейсер, эсминец

### 4. ✏️ Редактор (Editor)
- Создание и редактирование отсеков
- Рисование мышкой
- Настройка свойств отсеков

### 5. 🎨 Слои (Layer Editor) - НОВЫЙ
- Комбинированное отображение
- Фоновое изображение + полупрозрачные отсеки
- Интерактивное редактирование
- Настройка прозрачности

## Компонент CompartmentLayerEditor

### Основные возможности

1. **Загрузка фонового изображения**
   - Кнопка "📁 Загрузить изображение корабля"
   - Поддержка drag-and-drop
   - Удаление изображения

2. **Управление слоями**
   - Чекбокс "Показать отсеки"
   - Слайдер прозрачности (0-100%)
   - Переключение видимости

3. **Редактирование отсеков**
   - Рисование новых отсеков мышкой
   - Клик по отсеку для выбора
   - Настройка свойств (палуба, позиция)
   - Удаление отсеков

4. **Визуальная обратная связь**
   - Превью рисуемого отсека
   - Подсветка выбранного отсека
   - Цветовая индикация состояния
   - Индикаторы затопления и пожаров

### Интерфейс

```typescript
interface CompartmentLayerEditorProps {
  ship: Ship;
  backgroundImage: string | null;
  onBackgroundImageChange: (image: string | null) => void;
  compartments: Compartment[];
  onCompartmentsChange: (compartments: Compartment[]) => void;
}
```

### Использование

```tsx
<CompartmentLayerEditor
  ship={ship}
  backgroundImage={backgroundImage}
  onBackgroundImageChange={setBackgroundImage}
  compartments={ship.compartments}
  onCompartmentsChange={setCompartments}
/>
```

## Рабочий процесс

### Шаг 1: Загрузка изображения
1. Перейдите в режим "🎨 Слои"
2. Нажмите "📁 Загрузить изображение корабля"
3. Выберите файл с боковой проекцией корабля
4. Изображение появится на нижнем слое

### Шаг 2: Настройка прозрачности
1. Убедитесь, что чекбокс "Показать отсеки" включён
2. Настройте прозрачность отсеков (рекомендуется 50-70%)
3. Отсеки станут полупрозрачными поверх изображения

### Шаг 3: Размещение отсеков
1. Зажмите левую кнопку мыши
2. Нарисуйте прямоугольник отсека
3. Отпустите кнопку мыши
4. Отсек автоматически определит палубу и позицию

### Шаг 4: Редактирование отсеков
1. Кликните по отсеку для выбора
2. В панели свойств измените:
   - Палубу (верхняя/средняя/нижняя)
   - Позицию (нос/центр/корма)
3. Удалите ненужные отсеки

### Шаг 5: Настройка состояния
1. Выберите отсек
2. Измените его состояние:
   - Целый (зелёный)
   - Повреждён (оранжевый)
   - Затоплен (синий)
   - Разрушен (красный)
   - Пожар (оранжевый с огнём)

## Автоматическое определение

### Определение палубы
- **Верхняя палуба**: Y < 25 + superstructureOffset + deckHeight
- **Средняя палуба**: Y < 25 + superstructureOffset + 2 * (deckHeight + deckGap)
- **Нижняя палуба**: остальные Y координаты

### Определение позиции
- **Нос (bow)**: 0-15% длины
- **Носовая часть (forward)**: 15-35% длины
- **Центр (mid)**: 35-65% длины
- **Кормовая часть (aft)**: 65-85% длины
- **Корма (stern)**: 85-100% длины

## Технические детали

### SVG структура
```xml
<svg>
  <!-- Слой 1: Фоновое изображение -->
  <image href="..." opacity="0.8" />
  
  <!-- Слой 2: Отсеки (полупрозрачные) -->
  <g opacity="0.6">
    <rect ... /> <!-- Отсек 1 -->
    <rect ... /> <!-- Отсек 2 -->
    ...
  </g>
</svg>
```

### Обработка событий
- `onMouseDown`: начало рисования отсека
- `onMouseMove`: обновление превью
- `onMouseUp`: создание отсека
- `onClick`: выбор отсека

### Координатная система
- Начало координат: верхний левый угол
- X: слева направо (0 - width)
- Y: сверху вниз (0 - height)
- Отступы: padding = 20px
