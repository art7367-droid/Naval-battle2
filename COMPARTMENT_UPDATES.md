# Обновления системы отсеков

## Изменения

### 1. Уменьшена высота отсеков в 4 раза

**Было:**
- `deckHeight = 40px`
- `deckGap = 5px`

**Стало:**
- `deckHeight = 10px` (уменьшено в 4 раза)
- `deckGap = 2px`

**Где изменено:**
- `src/CompartmentLayerEditor.tsx` (2 места)
- `src/ShipSchematic.tsx` (1 место)

**Преимущества:**
- Более компактное отображение отсеков
- Лучше видны детали фонового изображения корабля
- Можно разместить больше отсеков по вертикали
- Улучшена визуализация надстроек линкоров

### 2. Добавлен счётчик отсеков

**Новый элемент интерфейса:**
```tsx
<div className="px-3 py-1 bg-cyan-900/50 border border-cyan-600 rounded text-xs font-bold text-cyan-300">
  📊 Отсеков на слое 2: {compartments.length}
</div>
```

**Расположение:** Панель управления в режиме "🎨 Слои"

**Функциональность:**
- Отображает общее количество отсеков на втором слое
- Обновляется в реальном времени при добавлении/удалении отсеков
- Выделен cyan цветом для заметности

### 3. Функциональность добавления и удаления отсеков

#### Добавление отсеков

**Способ 1: Рисование мышкой**
1. Зажмите левую кнопку мыши на SVG холсте
2. Нарисуйте прямоугольник нужного размера
3. Отпустите кнопку мыши
4. Отсек автоматически создаётся с определением:
   - Палубы (upper/middle/lower) на основе Y координаты
   - Позиции (bow/forward/mid/aft/stern) на основе X координаты

**Способ 2: Автоматическое создание**
- При загрузке корабля из базы данных отсеки создаются автоматически
- Количество отсеков зависит от длины корабля (каждые 10 метров)
- Количество палуб зависит от типа корабля:
  - Линкор: 3 палубы (upper, middle, lower)
  - Крейсер: 3 палубы (upper, middle, lower)
  - Эсминец: 2 палубы (upper, lower)

#### Удаление отсеков

**Способ 1: Через панель свойств**
1. Кликните по отсеку для выбора
2. В панели свойств нажмите кнопку "🗑️ Удалить отсек"
3. Отсек удаляется из списка

**Способ 2: Программное удаление**
```tsx
const deleteCompartment = (id: string) => {
  onCompartmentsChange(compartments.filter(c => c.id !== id));
  setSelectedCompartment(null);
};
```

## Примеры использования

### Пример 1: Добавление отсеков вручную

```
1. Выберите корабль на карте
2. Перейдите в режим "🎨 Слои"
3. Загрузите изображение корабля
4. Зажмите левую кнопку мыши
5. Нарисуйте прямоугольник в области корпуса
6. Отпустите кнопку мыши
7. Отсек добавлен, счётчик увеличился на 1
```

### Пример 2: Удаление отсеков

```
1. Выберите корабль на карте
2. Перейдите в режим "🎨 Слои"
3. Кликните по отсеку для выбора
4. Отсек выделен жёлтой рамкой
5. В панели свойств нажмите "🗑️ Удалить отсек"
6. Отсек удалён, счётчик уменьшился на 1
```

### Пример 3: Массовое редактирование

```
1. Загрузите изображение линкора
2. Счётчик показывает начальное количество отсеков (например, 81)
3. Удалите ненужные отсеки (счётчик уменьшается)
4. Добавьте новые отсеки в области надстроек (счётчик увеличивается)
5. Настройте прозрачность для лучшей видимости
6. Сохраните изменения
```

## Технические детали

### Автоматическое определение палубы

```typescript
const y = Math.min(drawStart.y, drawCurrent.y);
let deck: CompartmentDeck = 'upper';

if (y < 25 + superstructureOffset + deckHeight) {
  deck = 'upper';
} else if (y < 25 + superstructureOffset + 2 * (deckHeight + deckGap)) {
  deck = ship.type === 'destroyer' ? 'lower' : 'middle';
} else {
  deck = 'lower';
}
```

### Автоматическое определение позиции

```typescript
const x = Math.min(drawStart.x, drawCurrent.x);
const shipLength = ship.length || 250;
const numCompartments = Math.ceil(shipLength / 10);
const compartmentWidth = (width - padding * 2) / numCompartments;
const positionIndex = Math.floor((x - padding) / compartmentWidth);

let position: CompartmentPosition = 'mid';
const relativePos = positionIndex / numCompartments;

if (relativePos < 0.15) position = 'bow';
else if (relativePos < 0.35) position = 'forward';
else if (relativePos < 0.65) position = 'mid';
else if (relativePos < 0.85) position = 'aft';
else position = 'stern';
```

## Рекомендации по использованию

1. **Для линкоров:**
   - Используйте прозрачность 50-60%
   - Размещайте отсеки с учётом надстроек
   - Счётчик поможет отслеживать количество отсеков

2. **Для крейсеров:**
   - Используйте прозрачность 60-70%
   - 3 палубы позволяют детализировать повреждения
   - Счётчик показывает общее количество отсеков

3. **Для эсминцев:**
   - Используйте прозрачность 70-80%
   - Только 2 палубы (upper и lower)
   - Меньше отсеков, но более компактная схема
