# Визуализация кораблей

## Обновления

### Детализированные SVG-изображения кораблей

Корабли теперь отображаются с видом сверху (bird's eye view) вместо простых кругов с эмодзи.

## Характеристики

### Ориентация
- **6 направлений** по сторонам гексагональной сетки
- Поворот: 0°, 60°, 120°, 180°, 240°, 300°
- Нос всегда направлен в сторону движения

### Форма кораблей
- **Нос**: острый (треугольный)
- **Корма**: прямая (плоская)
- **Корпус**: вытянутый вдоль оси движения

### Различия между типами

#### 🚢 Линкор (Battleship)
- **Размер**: самый большой
- **Башни**: 3 (носовая, средняя, кормовая)
- **Труба**: прямоугольная
- **Мостик**: в носовой части
- **Цвет**: синий (игрок) / красный (противник)

#### ⛴️ Крейсер (Cruiser)
- **Размер**: средний
- **Башни**: 2 (носовая и кормовая)
- **Труба**: квадратная
- **Мостик**: в носовой части
- **Цвет**: синий (игрок) / красный (противник)

#### 🚤 Эсминец (Destroyer)
- **Размер**: самый маленький
- **Башни**: 1 (носовая)
- **Труба**: маленькая квадратная
- **Мостик**: компактный
- **Торпедные аппараты**: 2 (по бортам)
- **Цвет**: синий (игрок) / красный (противник)

## Технические детали

### Компонент ShipSprite
- **Файл**: `src/ShipSprite.tsx`
- **Props**:
  - `type`: тип корабля (battleship/cruiser/destroyer)
  - `heading`: направление (0-5)
  - `isPlayer`: принадлежность игроку
  - `size`: размер (по умолчанию 24)

### Интеграция в HexGrid
- **Файл**: `src/HexGrid.tsx`
- Размер корабля: `HEX_SIZE * 0.85` (чуть меньше гекса)
- Поворот через SVG transform: `rotate(${rotation})`

## Визуальные элементы

### Цветовая схема
- **Игрок**: синий корпус (#3b82f6), голубая палуба (#60a5fa)
- **Противник**: красный корпус (#ef4444), розовая палуба (#f87171)

### Детали
- **Башни**: тёмные круги с белой обводкой
- **Труба**: тёмный прямоугольник
- **Мостик**: полупрозрачный тёмный прямоугольник
- **Торпедные аппараты** (эсминец): маленькие прямоугольники по бортам

## Примеры использования

```tsx
// Линкор игрока, направленный вправо (0°)
<ShipSprite type="battleship" heading={0} isPlayer={true} size={24} />

// Крейсер противника, направленный вниз-вправо (60°)
<ShipSprite type="cruiser" heading={1} isPlayer={false} size={24} />

// Эсминец игрока, направленный влево (180°)
<ShipSprite type="destroyer" heading={3} isPlayer={true} size={24} />
```

## Преимущества

1. **Наглядность**: сразу видно тип корабля и его ориентацию
2. **Реалистичность**: форма соответствует реальным кораблям
3. **Различимость**: легко отличить линкор, крейсер и эсминец
4. **Тактическая информация**: направление носа показывает курс корабля
